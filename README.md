# Sanskrit_Compound_Classification
Project for CS 74 evaluating and comparing logistic regression, linear SVC and Naive Bayes for Sanskrit compound classification. 

# Dataset

This project uses the four-category SaCTI-base dataset from the
[SaCTI repository maintained by Ashish Gupta] (https://github.com/ashishgupta2598/SaCTI).

The notebook uses the supplied training, validation and test files in `data/coling/coarse`.

Dataset reference: Sandhan et al. (2022).
[A Novel Multi-Task Learning Approach for Context-Sensitive Compound Type Identification in Sanskrit](https://aclanthology.org/2022.coling-1.358/).
